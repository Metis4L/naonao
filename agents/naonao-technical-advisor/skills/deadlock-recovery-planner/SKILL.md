# SKILL: deadlock-recovery-planner

## 目标
处理“重复追问输入 / 缺上下文硬阻塞 / 状态混乱”的会话卡死问题，恢复流程控制权。

## 输入
- 卡死表现（重复文案 / 缺失字段 / 无法续接）
- 当前任务类型（执行 / 分析 / 设计）
- 已知状态（如基线/iter目标）

## 输出（固定结构）
1. 根因类型（workflow_problem / rule_problem / context_loss / permission）
2. 立即恢复动作（当前会话可发的一段话）
3. 备选恢复动作（新 session 启动包）
4. 无样本恢复模式（analysis-only）
5. 最小缺失字段格式（只提示一次）
6. 防复发建议（规则/状态机补丁）

## 规则
- 不重复索要同一字段
- 优先恢复为 analysis-only，再考虑索样本
- 输出必须给用户“可复制消息”
- 将“等待输入”与“无法继续”分开

## 验收标准
- 用户在 1~2 轮内恢复可推进状态
