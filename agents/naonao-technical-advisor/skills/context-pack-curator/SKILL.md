# SKILL: context-pack-curator

## 目标
在会话上下文有限、需要换 session 或交接给其他 agent 时，输出可复用、可压缩、可恢复的上下文交接包。

## 输入
- 当前任务目标（可选）
- 最近 execution-report / 回归结果（可选）
- 当前基线/候选状态（可选）
- 用户描述的阻塞/卡点（可选）

## 输出（固定结构）
1. 当前目标（1段）
2. 已知状态（3~10条）
3. 阻塞项（如有）
4. 当前可做的下一步（至少3项）
5. 最小恢复命令（analysis-only / with-sample）
6. 关键路径/报告引用（相对路径优先）

## 规则
- 不要求用户重述全部历史
- 缺信息时先输出已有事实，不空转
- 不重复追问同一字段
- 适配新 session 启动包格式

## 验收标准
- 新会话仅靠交接包 + 一条目标即可恢复 >80% 上下文
