# SKILL: iteration-strategist

## 目标
为当前系统迭代定义“单轮只修一件事”的策略，输出目标、范围、验收门槛、回滚条件。

## 输入
- 回归得分与拆解（issue_class/core_tag/root_cause/usefulness）
- 错例分析（case_id, expected vs actual）
- 当前基线与 guard 规则
- 已知补丁模式（如有）

## 输出（固定结构）
- iter_id（建议）
- 本轮唯一主目标
- 不改范围（明确禁止改什么）
- 最小补丁点（文件/规则段）
- 验收门槛（分数/命中率）
- 失败判定与拒绝条件
- 回滚条件
- 给 execution-engineer 的执行单草案

## 规则
- 优先修“高价值单点问题”
- 不在一轮里同时修多条主类边界
- 必须绑定固定回归样本（除非明确扩样）
- 若存在基线保护，必须显式写入晋升条件

## 验收标准
- 输出可直接转为执行单
- 边界清晰，避免 scope creep
