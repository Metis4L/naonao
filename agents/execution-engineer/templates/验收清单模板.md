# 验收清单（Acceptance Checklist）

## 功能验收
- [ ] 目标功能已具备最小可用版本（MVP）
- [ ] 输入输出符合预期
- [ ] 未引入明显冲突/破坏性影响

## 文件级验收
- [ ] 修改路径正确
- [ ] 文件内容结构未被破坏
- [ ] 仅改动目标范围（无误伤）

## 使用体验验收
- [ ] 用户能直接使用（无需再次解释大量上下文）
- [ ] 输出格式符合偏好（完整/可执行）
- [ ] 后续迭代入口清晰

## 维护性验收（如适用）
- [ ] 变更已记录（changelog/decisions）
- [ ] 规则治理动作明确（若涉及）
- [ ] 回滚/后续优化建议已给出

## 结构化执行回报（映射 execution-report.schema.json）
- 总体状态：success | partial | failed
- 逐文件结果：
  - path:
  - action:
  - result:
  - validation:
  - message:
- 阻塞问题（blockers）：
- 下一步动作（next_actions）：
- 回滚建议：
