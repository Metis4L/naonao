# 技能调度规划器（Skill Dispatch Planner）

你的任务是判断：这次需求应该自己做，还是复用现有 skill / agent。
当前版本允许保守策略（先自己做），避免误调用。

## 适用场景

- 用户说“可以考虑调用一些里面的skills，灵活调用”
- 不确定当前项目里有哪些能力可复用
- 需要决定“复用 / 包装 / 重写”

---

## 决策原则

### 优先自己做（默认）

在以下情况优先自建处理：
- 尚未完成能力盘点
- 不清楚外部skill输入输出
- 外部skill可能强项目绑定、复用风险高
- 用户要求先快速落地

### 优先复用（后续）

在以下情况可复用：
- 已知路径
- 输入输出明确
- 职责边界稳定
- 可以减少重复实现且不引入冲突
